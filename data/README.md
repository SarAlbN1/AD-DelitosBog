# Fuentes de datos

| Fuente | Uso |
|---|---|
| [MinDefensa — Hurto a personas](https://www.datos.gov.co/d/4rxi-8m8d) | Pronóstico diario para Bogotá, código 11001, entre 2018 y 2025. |
| [Secretaría Distrital de Seguridad — Delitos por localidad](https://oaiee.scj.gov.co/agc/rest/services/Tematicos_Pub/CifrasSCJ/FeatureServer/0) | Análisis territorial con conteos anuales. |
| [Línea 123 — Incidentes tramitados](https://datosabiertos.bogota.gov.co/dataset/incidentes) | Fuente complementaria para explorar reportes mensuales por zona. |
| [TransMilenio — Datos abiertos](https://validaciones.datosabiertos.transmilenio.gov.co/) | Fuente candidata para explorar movilidad según la cobertura disponible. |

Los archivos descargados pueden guardarse localmente en `DataSet/` o en `data/raw/`.
